# 1、日期筛选器展示值是否在范围内

## 1.1 IsMonthVisible

-- 层级筛选的时候，使用度量过滤筛选内容，实现联级效果，比如平台到店铺。
IsMonthVisible =
	/*
	功能：判断当前柱形图X轴的月份是否落在起止切片器选定的范围内
	返回：1（显示）或0（隐藏）
	*/
	// 步骤1：获取起始切片器选中的月份Key。
	// 若未选择，默认取主表的最小Key，确保全部显示
	VAR MinKey = IF(
	    ISFILTERED(Slicer_Month_Period_Min[TimeFrame_Value]),
	    MIN(Slicer_Month_Period_Min[TimeFrame_Key]),
	    MIN(Slicer_Month_Period[TimeFrame_Key])
	)
	// 步骤2：获取结束切片器选中的月份Key。
	// 若未选择，默认取主表的最大Key，确保全部显示
	VAR MaxKey = IF(
	    ISFILTERED(Slicer_Month_Period_Max[TimeFrame_Value]),
	    MAX(Slicer_Month_Period_Max[TimeFrame_Key]),
	    MAX(Slicer_Month_Period[TimeFrame_Key])
	)
	// 步骤3：获取当前筛选上下文（柱状图X轴遍历的当前行）的月份Key
	VAR CurrentKey = SELECTEDVALUE(Slicer_Month_Period[TimeFrame_Key])
	// 步骤4：判断当前月份Key是否在 [MinKey, MaxKey] 区间内
	RETURN
	    IF(
	        CurrentKey >= MinKey && CurrentKey <= MaxKey,
	        1,  // 在范围内：柱子显示
	        0   // 不在范围内：柱子隐藏
	    )

    IF(CurrentYear = MaxYear, 1, 0)

返回：1（显示）或 0（隐藏）
*/

// 步骤1：获取当前上下文中各字段的值（行粒度下 MAX 即当前行的值）

VAR IsLayerValid = NOT ISBLANK(LayerValue) && LayerValue <> ""

# 3、根据度量筛选维度-视觉对象级别筛选器

## 3.1 IsShopVisible_Optimized:店铺筛选器展示值是否在范围内

```dax
IsShopVisible_Optimized = 
VAR SelectedPlatforms = VALUES(Slicer_Platform_Selection[Platform_ID])
/*
3、IsShopVisible_Optimized:
度量名称：IsShopVisible_Optimized
功能：IsShopVisible的优化版本，减少计算量
返回：1（显示）或0（隐藏）
步骤1：获取当前筛选上下文中的平台ID
这是一个平台ID的列表（可能包含0个、1个或多个值）
*/
// 步骤2：判断并返回
RETURN
    IF(
        // 条件A：检查平台是否被筛选
        ISFILTERED(Slicer_Platform_Selection[Platform_ID]),
        // 如果筛选了平台：
        IF(
            // 条件B：使用CONTAINS函数检查当前店铺平台是否在已选平台中
            // CONTAINS(表, 表[列], 值) → 检查表中是否包含指定的值
            // SELECTEDVALUE(Slicer_Store_Name[Platform_ID])返回当前店铺的平台ID
            CONTAINS(
                SelectedPlatforms,      // 要搜索的表
                [Platform_ID],            // 表中的列（平台ID列）
                SELECTEDVALUE(Slicer_Store_Name[Platform_ID])  // 要查找的值
            ),
            1,  // 找到了：店铺应该显示
            0   // 没找到：店铺不应该显示
        ),
        // 如果没筛选平台：
        1  // 显示所有店铺
    )
```

## 3.2 IsMerchandiseRowVisible：辅助度量 — 矩阵行维度视觉对象级别筛选器

```dax
IsMerchandiseRowVisible = 
// ========================================
// 度量值: IsMerchandiseRowVisible
// Display Folder: Visual Filters
// 用途: 矩阵行维度视觉对象级别筛选器 —— Request Order 当期没值的行不展示
//       （判定对象: 主表四个行维度字段 brand / product_type / category_summary / category 所在行）
// 返回: 1（显示）或 0（隐藏）
// 依赖: Slicer_Time_Frame_Min[TimeFrame_Min], Slicer_Time_Frame_Max[TimeFrame_Max],
//       a02_e2e_boss_performance_summary_d
// 口径来源: 4.2 Act Base Value 的 __RequestOrderCnt_Act（Request Order 当期逻辑，原样提取，口径一致）
// 使用方式: 作为矩阵的视觉对象级别筛选器
//           筛选条件: IsMerchandiseRowVisible = 1
// 设计说明:
//   1. 判定指标: Request Order Qty Act（Metric_ID 6）—— o2o_fulfillment_request_order_cnt
//      的本期区间 SUM，calc_type = "fulfillment_category_summary_category_season_brand"
//   2. 行维度为事实表字段直接拉取，矩阵行的筛选上下文对 summary 表自动传递，
//      无需 __LevelFilter 桥接（桥接仅 Metric_ID 1, 2 桥接 request_data 表时需要）
//   3. 列维度 Dim_ColMetric_Fulfillment_PB_Merchandise 为断开维度，列标题（KPIGroup/ColName）
//      上下文不影响 summary 表聚合，同一行在所有列下的判定结果一致
//   4. 每一行在其自身层级上下文中独立判定: 明细行没值隐藏该明细行，父行聚合没值
//      则该父行及其全部子行不展示，全部行没值则矩阵无行可展示
//   5. "没值" = BLANK（所选时间范围内无任何明细行参与聚合）；若需把 0 也视为没值，
//      将返回条件改为 NOT ISBLANK(__RequestOrderCnt_Act) && __RequestOrderCnt_Act <> 0
// ========================================
    // ── 步骤1：时间筛选（与 4.2 Act Base Value 一致的全局时间范围）──
    VAR __TimeMin = SELECTEDVALUE(Slicer_Time_Frame_Min[TimeFrame_Min])
    VAR __TimeMax = SELECTEDVALUE(Slicer_Time_Frame_Max[TimeFrame_Max])
    // ── 步骤2：Request Order 当期逻辑（提取自 4.2 Act Base Value 的 __RequestOrderCnt_Act）──
    VAR __RequestOrderCnt_Act =
        CALCULATE(
            SUM('a02_e2e_boss_performance_summary_d'[o2o_fulfillment_request_order_cnt]),
            'a02_e2e_boss_performance_summary_d'[calc_type] = "fulfillment_category_summary_category_season_brand",
            'a02_e2e_boss_performance_summary_d'[data_date] >= __TimeMin,
            'a02_e2e_boss_performance_summary_d'[data_date] <= __TimeMax
        )
    // ── 步骤3：判断并返回 ──
    RETURN
        IF(
            // 条件：当前行的 Request Order 当期有值（非 BLANK）
            NOT ISBLANK(__RequestOrderCnt_Act),
            1,  // 有值：行显示
            0   // 没值：行隐藏（主表四个行维度字段不展示）
        )
// ═══ 行可见性判定表（Request Order 当期值 = BLANK → 该行隐藏）═══
// | 行类型                       | 判定上下文（矩阵行筛选自动传递）         | 没值时的表现                 |
// | 总计行                       | 全部行维度                               | 全部行不展示，矩阵无行可展示 |
// | brand 行（第1层）            | brand                                   | 该 brand 行及其子行不展示    |
// | product_type 行（第2层）     | brand + product_type                    | 该行及其子行不展示           |
// | category_summary 行（第3层） | brand + product_type + category_summary | 该行及其子行不展示           |
// | category 行（第4层）         | 四字段全匹配当前行值                     | 该明细行不展示               |
// ═════════════════════════════════════════════════════════
```

// ========================================
// 用途：严格按度量值结果判断，当前 Brand (行) 是否至少有一个 Co_Brand (列) 有真实数据
// 返回值：1 (显示该行), 0 (隐藏该行)

VAR __CurrentBrand = SELECTEDVALUE(Dim_Brand[brand])

VAR __AllVisibleCoBrands = ALLSELECTED(Dim_Co_Brand[co_brand])

                a03_e2e_customer_order_correlation_data_m[co_brand] = __CurrentCoBrand

# 6、筛选器过滤矩阵行ShowRow
调整后的行为：
本期有记录	LP 有记录	是否显示
有	        有	        显示
有	        无	        显示
无	        有	        显示，不再截掉历史数据
无	        无	        隐藏
ALL 也统一检查 TM、JD 的双期记录；金额为零或负数不影响行存在性。
2. 同文件里还有一个注意点
如果视觉对象还同时使用：
1.13 IsEmpty = 1：它通过本期上下文的 MAX 判断字段，可能再次排除仅 LP 有记录的行。
1.12 IsZero = 1：它把不同指标相加判断零，存在正负抵消误隐藏的风险。

```dax
ShowRow =
// ========================================
// 用途：本期或 LP 任一期存在记录时显示该行
// 口径：保留当前分类筛选，LP 只替换日期
// ========================================
    VAR __Platform =
        SELECTEDVALUE(Slicer_Platform_Selection[Platform_ID], "ALL")
    VAR __Cycle =
        SELECTEDVALUE(Slicer_DataCaliber_Selection[DataCaliber_ID], "T+1")
    VAR __LPStart = MIN(Dim_Date_Ly[LY_数据日期])
    VAR __LPEnd = MAX(Dim_Date_Ly[LY_数据日期])

    VAR __PlatformFilter =
        FILTER(
            ALL(a05_e2e_paid_media_product_data_d[platform]),
            IF(
                __Platform = "ALL",
                a05_e2e_paid_media_product_data_d[platform] IN {"TM", "JD"},
                a05_e2e_paid_media_product_data_d[platform] = __Platform
            )
        )

    // 本期：保留当前日期和行维度筛选
    VAR __CurrentRows =
        CALCULATE(
            COUNTROWS(a05_e2e_paid_media_product_data_d),
            __PlatformFilter,
            a05_e2e_paid_media_product_data_d[trans_cycle] = __Cycle
        )

    // LP：保留相同分类，只替换日期范围
    VAR __LPRows =
        IF(
            NOT ISBLANK(__LPStart) && NOT ISBLANK(__LPEnd),
            CALCULATE(
                COUNTROWS(a05_e2e_paid_media_product_data_d),
                __PlatformFilter,
                a05_e2e_paid_media_product_data_d[trans_cycle] = __Cycle,
                REMOVEFILTERS(Dim_Date_Current),
                FILTER(
                    ALL(Dim_Date_Current),
                    Dim_Date_Current[数据日期] >= __LPStart
                        && Dim_Date_Current[数据日期] <= __LPEnd
                )
            )
        )

    RETURN
        IF(__CurrentRows > 0 || __LPRows > 0, 1, 0)

```
