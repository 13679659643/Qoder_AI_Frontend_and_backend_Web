# 字段参数切换维度的度量适配原则

> status: ready
> created: 2026-11-13
> type: 知识沉淀 / DAX 模式
> 适用场景: 行维度通过字段参数（Field Parameter）在两档字段间切换（如 category_summary ↔ category），度量值不新建、不改名
> 应用案例: Customer/Class x Label Drilldown（Slicer_Dim_Category 字段参数，占比双列 ALLSELECTED + MAXX 按参数分支）
> 讨论来源: 2026-11-13 会话（4.18 辅助指标 MAXX 与占比分母适配方式差异）

---

## 1. 场景

视觉对象（条形图轴 / 表格列）改绑字段参数 `Slicer_Dim_Category`，通过参数切片器或书签+按钮切换行维度（category_summary / category 两档）。参数切换的是**轴/列的字段绑定**，行上下文筛选用哪个字段由参数决定，大部分度量自动按新维度分组，无需改动。

## 2. 核心结论

度量按用法分两类，适配方式完全不同：

| 类型 | 写法 | 是否需要感知当前维度 |
|---|---|---|
| 占比/分母类（筛选修饰器用法） | `ALLSELECTED('t05'[category_summary], 't05'[category])` 双列 | **不需要**，维度无关精确解 |
| MAXX/行迭代类（条形最大高度、Rank 等） | `SELECTEDVALUE(参数[Label])` 分支选迭代列 | **必须**，唯一需要感知维度的场景 |

## 3. 占比双列 ALLSELECTED 为什么不影响结果

1. **移除一个不存在的筛选 = 空操作**：轴为 category_summary 时移除 category 的筛选等于什么都没做，反向同理——两种状态下结果都精确正确，不是近似
2. **分母不迭代维度值**：只做一次聚合，产出"当前外部筛选下的总量"这一个标量，与轴上显示哪些行、几行完全无关
3. **ALLSELECTED 保留显式筛选**：视觉对象筛选框里"移除空维度/不为空"这类显式筛选被保留，分母口径自动与可见行对齐；空维度行聚合进总量也是分母本应含的部分（显示层的事，不影响比值）

## 4. MAXX 为什么必须按维度分支

`MAXX(ALL('t05'[category]), [V])` 写死了迭代列，行上下文筛的是那一列，轴一换就错：

1. **粒度错位且双向都错**：
   - 可加指标（SLS）：细粒度每份 ≤ 所属粗粒度汇总值，`categoryMax ≤ summaryMax` → 轴为粗粒度时条形最高柱可能**超过**算出的"最大值"，数据条 >100%，比例尺爆掉
   - 反向固定粗粒度：轴为细粒度时最大值偏大，最高柱永远不满格
   - 半可加指标（Customer No. 去重）：细粒度用户集 ⊆ 所属粗粒度用户集，两粒度最大值不相等
2. **双列/嵌套构造不出正确写法**：`ALL(c1, c2)` 返回组合粒度，迭代它筛"c1=x 且 c2=y"的交叉行，不是任何一档轴的粒度；嵌套 `MAXX(ALL(粗), MAXX(ALL(细), V))` 内层对每行均为常数，整体等于固定粗粒度最大值，必有一档轴错误
3. **空维度陷阱**：`ALL(col)` 移除该列上**一切**筛选，包括筛选框里"不为空"的显式筛选 → 空维度行被 MAXX 迭代进去；若空维度行度量值非空（如"无品类"订单聚合值），最大值可能来自视觉上看不见的行 → 全部条形错误缩放。把 `ALL` 换 `ALLSELECTED` 可保留显式筛选，但粒度错位仍在，分支省不掉

## 5. 代码模式

```dax
// 占比分母（维度无关，双列 ALLSELECTED）
VAR __Denominator =
    CALCULATE(
        [Net_Customer No. Value],
        ALLSELECTED('t05_customer_order_data_d'[category_summary], 't05_customer_order_data_d'[category])
    )

// MAXX 条形最大高度（按字段参数值分支，唯一需感知维度的场景）
VAR __Dim = SELECTEDVALUE('Slicer_Dim_Category'[Label], "Category")
VAR __MaxByCategory  = MAXX(ALL('t05_customer_order_data_d'[category]),         [Net_Customer No. Value])
VAR __MaxBySummary   = MAXX(ALL('t05_customer_order_data_d'[category_summary]), [Net_Customer No. Value])
RETURN
    IF(__Dim = "Category Summary", __MaxBySummary, __MaxByCategory)
```

## 6. 一句话记忆

> **占比看"筛掉什么"（双列移除，空操作无害）；MAXX 看"迭代哪一列"（粒度必须等于当前轴）——前者维度无关，后者必须读参数值分支。**

## 7. 字段参数方案整体要点（补充）

- 字段参数切片器**只影响绑定了该参数的视觉对象**，不作为筛选器过滤其它视觉（未绑定的子模块不受影响）
- 参数 Order 0 在前 = 默认选中，与改造前行为一致
- 书签+按钮切换时，书签用"所选视觉对象"模式仅捕获参数切片器，避免连带恢复其它切片器当时的选择状态
- 交叉筛选按当前激活字段的值传递（点击 category 柱子按 `t05[category]` 过滤其它视觉）
- 字段参数要求 Power BI Desktop 2022 年 11 月及以后版本
